# ฐานข้อมูลรายวิชา หลักสูตร 2567

เว็บค้นหาและดูแลข้อมูลรายวิชาตามหลักสูตรประกาศนียบัตรวิชาชีพ (ปวช.) และประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) พุทธศักราช 2567
รองรับหลายสาขา รายชื่อสาขาและไฟล์ PDF ต้นฉบับอยู่ใน `Data/programs.json` ตอนนี้มี:

| ระดับ | รหัส | สาขาวิชา | PDF (หน้า) |
|---|---|---|---|
| ปวส. | 31901 | เทคโนโลยีสารสนเทศ | `31901v7_18_10_68.pdf` (37–106) |
| ปวช. | 21901 | เทคโนโลยีสารสนเทศ | `ปวช-เทคโนโลยีสารสนเทศ-21901.pdf` (14–81) |

- **หน้าสาธารณะ:**
  - `/` รายชื่อหลักสูตรแยก ปวช./ปวส. พร้อมช่องค้นหาทุกสาขา
  - `/p/<รหัสสาขา>` รายวิชาของสาขา: ค้นหา กรองตามหมวด/หน่วยกิต ส่งออก Excel พิมพ์/บันทึก PDF และแดชบอร์ด (`/p/<รหัสสาขา>/dashboard`)
  - `/search` ค้นหาข้ามสาขา แต่ละวิชามีป้ายบอกว่าอยู่สาขาไหน
  - `/courses/<รหัสวิชา>` รายละเอียดวิชา และตาราง "อยู่ในหลักสูตร" (ระดับ สาขา หมวด)
- **หน้าผู้ดูแล (`/admin`):** จัดการสาขา หมวดวิชาของแต่ละสาขา และรายวิชา รวมถึงกำหนดว่าวิชาอยู่สาขา/หมวดไหน (ADMIN และ STAFF) จัดการผู้ใช้ (ADMIN เท่านั้น)

เทคโนโลยี: Next.js 15, PostgreSQL 16 (Docker), Prisma, Auth.js, Tailwind CSS

## ติดตั้งและรันครั้งแรก

ต้องมี Node.js 20 ขึ้นไป และ Docker Desktop

```bash
npm install
cp .env.example .env          # แล้วแก้ AUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
docker compose up -d          # PostgreSQL ที่พอร์ต 5432 (สร้างฐาน courses และ courses_test)
npx prisma migrate deploy
npm run extract               # ทุกสาขาในทะเบียน: PDF → Data/extracted/<รหัสสาขา>.json และ <รหัสสาขา>.report.txt
npx prisma db seed            # นำเข้ารายวิชาทุกสาขาตามลำดับในทะเบียน และสร้างบัญชีผู้ดูแลระบบคนแรก
npm run dev                   # http://localhost:3000
```

`Data/extracted/` ถูก commit ไว้แล้ว ถ้าไม่ได้แก้ตัวแยกข้อมูล ข้าม `npm run extract` ได้
ไฟล์ PDF ต้นฉบับไม่อยู่ใน git ต้องวางไว้ที่ `Data/` เองถ้าจะรัน extract

สร้าง `AUTH_SECRET` ได้ด้วย `openssl rand -base64 32`

## รันแบบ container

ทุกครั้งที่ push เข้า `main` GitHub Actions จะ build image แล้วส่งขึ้น `ghcr.io/eadsrichai/subject:latest` (ดู `.github/workflows/container.yml`)

```bash
docker compose --profile app pull                          # ดึง image ล่าสุด (หรือ build เองด้วย --profile app build)
docker compose --profile app up -d                         # ฐานข้อมูล + เว็บที่ http://localhost:3000
docker compose --profile app run --rm app npx prisma db seed   # นำเข้าข้อมูลครั้งแรก
```

- container จะรัน `prisma migrate deploy` ทุกครั้งก่อนเปิดเว็บ
- ค่า `AUTH_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` อ่านจาก `.env`
- image ใน ghcr.io เป็น private ตั้งแต่แรก ถ้าจะให้คนอื่นดึงได้ ต้องเปลี่ยนเป็น public ที่ Package settings บน GitHub

## บัญชีผู้ใช้

- บัญชีผู้ดูแลระบบคนแรกสร้างจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` ตอน seed (รหัสผ่านอย่างน้อย 8 ตัวอักษร)
- **เปลี่ยนรหัสผ่านทันทีหลังเข้าสู่ระบบครั้งแรก** ที่เมนู "บัญชีของฉัน"
- รัน seed ซ้ำจะไม่สร้างบัญชีซ้ำ และไม่เปลี่ยนรหัสผ่านของบัญชีที่มีอยู่
- ไม่มีหน้าสมัครสมาชิก ผู้ดูแลระบบเพิ่มผู้ใช้ได้ที่เมนู "ผู้ใช้"
- ระบบไม่ยอมให้ปิดการใช้งานหรือลดบทบาทผู้ดูแลระบบคนสุดท้าย
- ผู้ใช้ที่ถูกปิดการใช้งานจะถูกตัดออกทันทีในการกระทำครั้งถัดไป แม้ยังล็อกอินค้างอยู่

## นำเข้าข้อมูลซ้ำ

```bash
npm run extract                 # ทุกสาขา
npm run extract -- 21901        # เฉพาะสาขาที่ระบุ (ระบุได้หลายรหัส)
npx prisma db seed              # ข้ามรายวิชาที่ถูกแก้ผ่านหน้าเว็บแล้ว
npx prisma db seed -- --force   # เขียนทับด้วยข้อมูลจาก PDF (การแก้ไขผ่านเว็บจะหาย)
```

seed พิมพ์สรุปทีละสาขา เช่น
`21901: เพิ่ม 119, อัปเดต 0, ใช้ร่วม 0, เติมช่องว่าง 0, เนื้อหาไม่ตรง 0, ข้าม (แก้ไขผ่านเว็บแล้ว) 0`
สาขาที่ยังไม่มีไฟล์ `Data/extracted/<รหัสสาขา>.json` จะถูกข้าม

ไม่มี `--force` seed จะไม่ทับชื่อ/ลำดับสาขา หมวด และตำแหน่งของวิชาที่มีอยู่แล้ว (อาจถูกแก้ผ่านเว็บ) และไม่ลบวิชาที่หายไปจากเล่ม

### วิชาที่ใช้ร่วมหลายสาขา

รหัสวิชาเดียวกันคือวิชาเดียวกัน มีเนื้อหาชุดเดียว แต่ละสาขากำหนดหมวดของวิชานั้นเองได้

- สาขาแรกที่นำเข้าวิชานั้นเป็น **เจ้าของเนื้อหา** seed รอบถัดไปของสาขานั้นจึงอัปเดตเนื้อหาได้
- สาขาอื่นที่มีวิชาเดียวกัน **เติมได้เฉพาะช่องที่ยังว่าง** ช่องที่มีค่าอยู่แล้วแต่ไม่ตรงกันจะไม่ถูกทับ
  วิชานั้นจะถูกทำเครื่องหมาย "ต้องตรวจสอบ" พร้อมหมายเหตุ `เนื้อหาต่างจากหลักสูตร <รหัสสาขา>: <ชื่อช่อง>`
- แก้เนื้อหาวิชาที่ใช้ร่วมในหน้าผู้ดูแล การแก้ไขจะมีผลกับทุกสาขาที่ใช้วิชานี้ (ฟอร์มมีคำเตือน)

## เพิ่มสาขาใหม่

1. วาง PDF เล่มหลักสูตรไว้ที่ `Data/`
2. เพิ่มรายการใน `Data/programs.json`: `code` (รหัสสาขา 5 หลัก), `level` (`PVC` = ปวช., `PVS` = ปวส.), `name`, `typeName` (ประเภทวิชา), `pdf` (ชื่อไฟล์) และ `pages`
   - `pages` = `[หน้าแรก, หน้าสุดท้าย]` ตามเลขหน้าของไฟล์ PDF (ไม่ใช่เลขที่พิมพ์ในเล่ม) ดูจากสารบัญ:
     ตั้งแต่หน้าแรกของ **โครงสร้างหลักสูตร** ถึงหน้าสุดท้ายของ **คำอธิบายรายวิชา**
   - ลำดับในไฟล์คือลำดับการแสดงผลและลำดับการ seed
3. `npm run extract -- <รหัสสาขา>`
4. เปิด `Data/extracted/<รหัสสาขา>.report.txt` เทียบจำนวนหมวด/วิชากับตารางโครงสร้างในเล่ม และดูรายการ "ต้องตรวจสอบ"
5. `npx prisma db seed`
6. อ่านบรรทัดของสาขาใหม่ในผลลัพธ์ ถ้า "เนื้อหาไม่ตรง" ไม่ใช่ 0 ให้ตรวจวิชาที่ติดธงในหน้า `/admin`
   (ตาราง "แยกตามสาขา" มีลิงก์ไปยังวิชาที่ต้องตรวจของแต่ละสาขา)

เพิ่มสาขาผ่านหน้า `/admin/programs` ได้เช่นกัน (กรณีไม่มี PDF) แล้วสร้างหมวดที่ `/admin/categories` และเลือกสาขาให้วิชาในฟอร์มวิชา

`Data/extracted/<รหัสสาขา>.report.txt` สรุปจำนวนวิชาต่อหมวดและรายวิชาที่ต้องตรวจสอบ
วิชาที่ต้องตรวจสอบแสดงในหน้า `/admin` พร้อมเหตุผล

### ข้อจำกัดของข้อมูลจาก PDF

- เล่ม 31901: คำอธิบายรายวิชาของ **หมวดวิชาสมรรถนะแกนกลาง (91 วิชา)** ไม่อยู่ในเล่ม (PDF หน้า 58 ระบุว่า "ตามเอกสารนอกเล่ม")
  วิชาเหล่านี้มีเฉพาะรหัส ชื่อ และ ท-ป-น กรอกคำอธิบายเพิ่มได้ผ่านหน้าผู้ดูแล
- เล่ม 31901 พิมพ์รหัส `30901-2008` ไว้บนคำอธิบายของวิชา `31901-2008` ระบบรวมให้แล้วและทำเครื่องหมาย "ต้องตรวจสอบ"
- ข้อความที่ขึ้นบรรทัดใหม่ใน PDF ถูกต่อกันโดยไม่เว้นวรรค บางรายการจึงติดกัน และมีช่องว่างแทรกกลางคำบ้าง
  (มาจากต้นฉบับ) แก้ได้ผ่านหน้าผู้ดูแล

## การทดสอบ

```bash
npm test            # unit: ตัวแก้ข้อความไทย ตัวแยก PDF ตัวกรอง Excel การตรวจข้อมูลฟอร์ม
npm run test:db     # กับฐานข้อมูล courses_test: ค้นหา seed สิทธิ์ การจัดการรายวิชาและผู้ใช้
npm run test:e2e    # เบราว์เซอร์จริง (build แล้วรันที่พอร์ต 3100 บน courses_test)
```

ต้องรัน `docker compose up -d` ก่อน `test:db` และ `test:e2e`
ครั้งแรกของ e2e ต้องติดตั้งเบราว์เซอร์: `npx playwright install chromium`

## โครงสร้างโค้ด

| ที่อยู่ | หน้าที่ |
|---|---|
| `scripts/pdf/` | แยกข้อมูลจาก PDF: จัดบรรทัด (`lines.ts`) แยกรายวิชา/หมวด (`parse.ts`) CLI (`extract.ts`) |
| `lib/normalize-thai.ts` | แก้อักขระไทยที่เพี้ยนจาก PDF (ใช้กับช่องค้นหาด้วย) |
| `Data/programs.json`, `lib/program-registry.ts` | ทะเบียนสาขา (ขับทั้ง extract และ seed) |
| `lib/programs.ts` | รายชื่อสาขา และกฎเพิ่ม/แก้/ลบสาขา |
| `lib/courses.ts`, `lib/course-filter.ts` | ค้นหา (ในสาขาหรือข้ามสาขา) กรอง แบ่งหน้า สถิติ |
| `lib/course-admin.ts`, `lib/users.ts` | กฎการแก้ไขรายวิชา หมวด และผู้ใช้ |
| `lib/authz.ts` | ตรวจสิทธิ์จากฐานข้อมูลทุกครั้ง (`requireRole`, `runAs`) |
| `lib/seed-data.ts`, `prisma/seed.ts` | นำเข้าข้อมูลทุกสาขา (กติกาวิชาร่วม) และสร้างผู้ดูแลระบบคนแรก |
| `app/(public)/(site)/` | หน้าแรก ค้นหาข้ามสาขา รายละเอียดวิชา |
| `app/(public)/p/[code]/` | หน้าของแต่ละสาขา: รายวิชา แดชบอร์ด พิมพ์ |
| `app/admin/` | หน้าผู้ดูแล และ server actions |
| `docs/superpowers/` | เอกสารออกแบบและแผนการพัฒนา |
